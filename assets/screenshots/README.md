# Screenshots

Guardá acá las capturas que vas a mostrar en el README y en la documentación.

Nombres sugeridos:

- `overview.png` para la vista principal
- `step-by-step.png` para una operación guiada
- `exercises.png` para la lista de ejercicios o presets

Si querés agregar más imágenes, mantené nombres descriptivos y consistentes.
